Quick Workflow Summary (TL;DR)
  1. Right-click directly on the picture or photo on any webpage and select "Copy image".
  2. Paste it into your document or workspace with Ctrl + V (or Cmd + V on Mac).
  3. To avoid losing where the image came from, use FloatBoard to automatically pin the source URL with the picture.

Open the source page before copying

Start from the page where the image is presented with its title, creator, context and usage information, not from a search thumbnail alone. The recorded example opens a tree photograph on a photography site after browsing search results. That extra step matters: a thumbnail can be cropped, cached or detached from information you will need later. A source page also helps you locate a proper download if you later decide to use the image in a design.

Write down the page URL in your project note before you copy anything. If the page names the photographer or creator, record that too. If it links to specific terms, save the relevant link or a note that you checked it on a particular date. Do not rely on a clipboard manager to reconstruct this context from the image alone. That is rarely what an image clipboard item contains.

Know what the browser menu choices give you

Most desktop browsers expose related but different actions when you right-click an image. Copy Image places image data on the clipboard for pasting into an app that accepts it. Copy Image Address or a similarly named command copies a file URL, which may be temporary, resized or served by a content delivery network. Copy Link may refer to the clicked link rather than the image itself. Read the actual menu label before choosing.

The clip above shows the opened source page beside image tiles; it does not demonstrate this menu action. Browser wording and behavior vary, so verify what was pasted in the target app. If a site prevents direct copying, look for its intended download or sharing path and follow its terms. If your goal is only to cite or return to the photo, the source page URL may be all you need.

Paste a working reference without treating it as an archive

After copying, paste into an image-accepting destination and confirm that you got image pixels rather than a URL or plain text. In FloatBoard, use the image-add workflow supported by your installed version; keep the board beside the source page while you decide whether the photograph helps. If the tile displays only a cropped view, compare it with the opened image before concluding that the subject or negative space is right for your task.

Ask a narrow question such as “Does this tree silhouette work as a shape reference?” or “Would its open sky leave room for a caption?” The recording is from Linux in July 2026, so current controls can differ. Keep a minimal source record beside the image

A useful record has five fields: source page URL, creator, image title or description, the reason you saved it, and the usage terms you actually checked. If a field is unknown, write “unknown” rather than guessing. For example: “Single tree in pale field; source page URL; photographer named on page; study negative space only; publication permission not yet reviewed.” This takes less time than rediscovering an image from a screenshot weeks later.

Keep your own observation separate from text copied from the source page. If you paste a title or description, mark it as a quote and link back. This is particularly helpful when the original image is edited, removed or replaced. A short record makes your visual reference useful after the immediate clipboard state has changed, without pretending that FloatBoard itself is a provenance database.

Separate permission to study from permission to publish

Saving a private working reference and publishing a photograph in an app, ad or client website are different acts. Before publication, read the source site's current license and any restrictions shown for that particular image. Consider whether the image includes a recognizable person, logo or property that needs additional clearance for your use. A context-menu copy action says nothing about those permissions.

If the terms do allow your use, obtain the appropriate original file through the source's intended route and keep the terms with your project record. If you cannot establish a reliable source or suitable permission, choose another image. Do not silently substitute a browser screenshot or crop: it can lower quality while leaving the rights question unresolved. The most responsible workflow is also the easiest one to hand over to a client or teammate.

When the pasted result is wrong

If pasting yields a URL instead of pixels, you probably copied the image address or link. Return to the source page and choose the image-data command if available. If the target app does not accept image clipboard data, use its image-import method with a file obtained under the source site's terms. If the image looks blurry, the browser may have copied a preview or a low-resolution variant; inspect the original asset rather than enlarging the pasted copy.

If the clipboard has changed before you paste, revisit the source page using the URL you saved. This is another reason to record it before copying. If several similar results are open, label each source in your notes. The clipboard is transient; it is a poor way to remember which of five nearly identical tree photographs a pasted image came from.

Move from one source to a coherent working set

After the first paste, do a retrieval test: close the source tab, then use the page URL in your note to find the exact photograph again. If you cannot tell which image on a multi-photo page you meant, add its title, creator name or a short visual description. This is faster than searching for a vague phrase such as “tree in field” after the browser history has filled with similar results. The test also reveals whether you saved the source page or only a temporary file address.

Now decide whether the copy stays a temporary shape reference or becomes a candidate for published work. For the first case, a labelled working tile may be enough. For the second, revisit the source's terms, get a suitable file and make a real layout test; the clipboard preview is not the final asset. If you need several different tree forms, use the attribute-led search workflow to assign each a role rather than collecting lookalikes.

Frequently asked questions

Why did pasting give me a URL instead of a picture?

You may have chosen Copy Image Address or Copy Link. Return to the image and choose the image-data command if the browser offers it, then verify the pasted result.

Why isn't the source link attached to my copied image?

Image clipboard data and page context are separate. Record the page URL and enough detail to identify the image before you move away.

Can I publish a copied web image?

Only after checking the source terms and any permissions needed for your use. A successful copy action says nothing about publication rights.
