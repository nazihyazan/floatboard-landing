Download FloatBoard

Get floating desktop notes and a clipboard manager for text and images. Choose your operating system, install FloatBoard, and keep your references visible above your other windows.

The free plan includes 5 texts per day, 5 images per day and one window. Compare Free and Premium before upgrading.

Download for Linux

Linux version 1.0.17. On a system with Snap installed, use the stable Snap Store release to receive updates automatically:

sudo snap install floatboard

Already installed? Close FloatBoard and run sudo snap refresh floatboard.
