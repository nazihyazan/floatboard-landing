Frequently Asked Questions

How does this free online OCR tool work?

The tool uses Tesseract.js compiled to WebAssembly. When you drop or paste an image, the OCR engine analyzes character pixel patterns directly in your computer's RAM without making external HTTP API requests.

Can I paste screenshots directly from the clipboard?

Yes. Simply press Win + Shift + S on Windows (or Cmd + Shift + 4 on Mac) to snip any part of your screen, then press Ctrl + V on this page to recognize the text instantly.

What languages are supported?

English, programming code syntaxes, numbers, and Latin alphabets are supported out of the box with high accuracy.

How does this compare to Windows PowerToys Text Extractor?

PowerToys Text Extractor requires local Windows installation and administrative permissions, and only copies text blindly to the clipboard. FloatBoard lets you review the original image crop beside the editable text to verify accuracy before pasting.
