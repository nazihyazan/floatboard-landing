Frequently Asked Questions

How does the online image comparison tool work?

The tool uses modern browser APIs (FileReader and HTML5 Canvas) to render two images in parallel memory. You can toggle between side-by-side view, draggable before/after slider, and difference overlay without sending data over the network.

Is there any file size limit for image comparison?

Because processing happens locally in your device RAM, you can compare large 4K and 8K PNG, JPG, or WebP images up to your system memory capacity without upload timeouts.

How do I compare vehicle blueprints or 3D renders?

Load your front orthographic view in Slot A and your side orthographic view in Slot B. You can inspect alignment, silhouette proportions, and edge loop curvature side by side. For Blender workflows, the desktop app pins this board directly over your 3D Viewport.

Can I run this comparison board offline on my computer?

Yes. The standalone FloatBoard desktop app runs natively on Windows 11/10, macOS, and Linux without internet access. It pins reference boards always-on-top above any application.
