How Document Picture-in-Picture Works

Historically, web browsers only supported Picture-in-Picture for HTML5 <video> elements. The newer Document Picture-in-Picture API allows web applications to open an arbitrary, always-on-top desktop window containing full interactive HTML, styled CSS, and live JavaScript.

When you click "Pop Out (Always on Top)", FloatBoard WebPad requests an OS-level top-most window directly through your Chromium browser. The editor transfers seamlessly into this detached viewport without dropping state, allowing you to edit meeting notes, keep documentation beside code, or review checklists while working inside VSCode, Zoom, Excel, or games.

Frequently Asked Questions

Is FloatBoard WebPad really 100% free?

Yes. WebPad is completely free with no user accounts, no subscriptions, and no advertisements. It is provided by FloatBoard as a demonstration of modern browser capabilities.

Is my data stored securely?

All notes typed into FloatBoard WebPad are stored exclusively inside your browser's local localStorage cache. No text is ever uploaded to any cloud server, third-party database, or analytics platform.

Why did my floating window close when I closed the browser tab?

Because the Document Picture-in-Picture window is tied to the lifecycle of the web page that opened it. If you close the browser tab, the floating window closes automatically. If you require persistent windows that remain open across reboots and browser closures, download the native FloatBoard Desktop app.

Can I download my notes as a file?

Yes. Click the Save .txt button in the top action bar at any time to export the full plain text contents of your notepad directly to your Downloads folder.
